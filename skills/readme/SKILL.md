# README — 项目 README 维护标准

## 结构标准

项目 `README.md` 应包含以下章节（按需选用）：

### 1. 标题与徽章

- 项目名称 + 一句话定位
- 技术栈徽章（Python / Node / Go 等）
- License 徽章

### 2. 导航（推荐）

锚点链接到各主要章节，方便长文档快速跳转。

### 3. 快速开始

最简路径让用户跑起来。控制在 5 行以内：
- 克隆 → 安装依赖 → 启动 → 验证

### 4. 核心功能 / 架构图

- 功能列表（✅ 格式）
- 系统架构图（ASCII art）
- 核心模块表（模块名 | 文件 | 说明）

### 5. API 概览

| 端点前缀 | 说明 | 文档 |
|---------|------|------|

### 6. 示例 / 使用演示

- 最小可运行示例的路径或代码片段
- 常见场景的 CLI 命令

### 7. 贡献 / 团队

- 作者信息
- 团队主页链接
- 贡献指南链接（如有）

## 维护规则

- 新增核心功能 → 更新功能列表
- 新增 API 端点 → 更新 API 概览表
- 新增示例 → 更新示例链接
- 环境要求变更 → 更新快速开始
- 架构变更 → 更新架构图
