# 00 — 任务分流

## 这个文件干什么

不知道该用哪个 prompt 时，先从这里开始。它负责判断当前任务属于需求、计划、实现、审查、验收、故障、交接还是收尾。

## 什么时候用

- 只有一句模糊描述，不知道下一步该做什么
- 任务横跨多个阶段
- 当前环境不确定有哪些 skill/trigger 可用
- 不确定该用 Claude Code 还是 Codex

## 用什么模型

用 **GPT 5.5（Codex）**——分流需要理解上下文和流程依赖。

## 怎么用

在 Codex 或 Claude Code 里输入：

```
请帮我分流这个任务：[任务描述]。
判断它应该进入哪个 prompt，并说明为什么。
如果当前环境缺少对应 skill，给 fallback 做法。
```

## 会得到什么

- 推荐入口
- 不推荐入口及原因
- 需要先补的上下文
- 如果 skill 不存在，如何手动执行同等流程
