# API Contract：[接口组名称]

## 这个文件干什么

前后端之间的合同。接口路径、请求参数、响应结构、错误码——白纸黑字写清楚。**后端按这个实现，前端按这个调用，谁改谁同步**。

## 什么时候写/改

- 新增接口
- 改请求参数或响应字段
- 改状态码
