# 性能基线

## 这个文件干什么

记录每个关键接口的性能目标。**验收的时候拿这个对比，不达标不算过**。

## 指标定义

| 指标 | 含义 |
|------|------|
| P50 | 50% 的请求比这个快 |
| P95 | 95% 的请求比这个快 |
| P99 | 99% 的请求比这个快 |

## 基线记录

| 接口 | 场景 | P50 目标 | P95 目标 | 实测 | 日期 |
|------|------|----------|----------|------|------|
| | | | | | |

## 更新规则

- 新增接口时加一行
- 每次 diagnose 验收后更新实测值
- 如果实测严重偏离目标（>2x），讨论是不是目标定错了还是性能退化
