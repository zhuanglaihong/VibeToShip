# RFC：[功能名称]

## 这个文件干什么

[[../../prompts/01-需求夯实-grill-me]] 跑完之后，把结果沉淀成这个 RFC 文档。**这是 grill-me 的输出物，不是输入物**。

## 什么时候写

grill-me 通过后，把 AI 输出的设计整理到这个模板里，留作团队共享的设计文档。

## 模板正文

### 1. 定位

本RFC要解决什么问题？一句话说清楚。

### 2. 目标与边界

做什么、**不做什么**（边界比目标更重要）。

### 3. 资源模型

有哪些实体？关系是什么？

### 4. 数据模型

表结构、字段说明、索引。

### 5. API 设计

端点列表、请求参数、响应结构、错误码。

### 6. 查询链路

从请求到响应的完整数据流。

### 7. 状态码契约

| 场景 | 状态码 | 说明 |

### 8. 分期

Phase 1 做什么、Phase 2 做什么、Phase 3 做什么。

### 9. 实施计划

拆成几个 commit，每个 commit 改什么文件。

### 10. 风险与假设

哪里可能出问题？依赖什么前提？

## 这个文档的输出流向

RFC 写完后 → 触发 [[../../prompts/02-计划拆解-writing-plans]] 拆 commit
